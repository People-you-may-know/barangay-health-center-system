# Week 12 — Individual Unassisted Defense Checklist

The oral defense is individual and unassisted. Use this file to prepare beforehand, but do not use AI during the actual defense.

## Be able to explain your own code

- What does your file/module do?
- Why did you choose this approach?
- What happens when the input is invalid?
- What happens when a requested record does not exist?
- Where does validation live?
- How does the request move from the UI to the Flask controller and back?
- What automated tests cover the behavior you changed?
- What did the Week 10 QA process discover?
- How was the P1 date-validation bug fixed in Week 11?
- What would you improve if the project continued?

## Demonstrate understanding, not memorization

Explain the reasoning behind the code in your own words. If you do not know an answer, state what you know and what you would investigate rather than inventing an explanation.

## Final readiness

- [ ] I can explain my own commits.
- [ ] I can explain the validation path.
- [ ] I can explain at least one test I contributed to.
- [ ] I understand the known limitations of the current in-memory data store.
- [ ] I know the live demo click-path.
- [ ] I know the backup demo plan.
